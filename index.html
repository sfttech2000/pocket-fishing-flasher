Pocket Fishing · cozy fishing game

ติดตั้ง Pocket Fishing ผ่านเบราว์เซอร์

เกมตกปลาสบายๆ บนจอ CYD (ESP32-2432S028R จอเหลือง 2.8") ติดตั้งครั้งแรกหรืออัปเดต ไม่ต้องลงโปรแกรม ใช้ได้ทั้งคอมพิวเตอร์ (Chrome หรือ Edge) และมือถือ Android (Chrome กับสาย OTG)

เวอร์ชัน …ฟรีออฟไลน์ 100%ไม่ใช้ microSDทุกรุ่นจอต่อจอยบลูทูธได้
เบราว์เซอร์นี้ใช้ไม่ได้
เปิดหน้านี้ด้วย Google Chrome หรือ Microsoft Edge บนคอม หรือ Chrome บนมือถือ Android · iPhone และ iPad ใช้ไม่ได้ (Apple ไม่เปิดให้เว็บใช้พอร์ต USB)

1. เสียบบอร์ด

  1. คอม: เสียบด้วยสาย USB ที่ส่งข้อมูลได้ และปิดโปรแกรมอื่นที่อาจใช้พอร์ต เช่น Arduino IDE, Serial Monitor
  2. มือถือ: ใช้สาย USB-C ↔ USB-C หรือหัวแปลง OTG จอบอร์ดควรติด (OPPO, realme, vivo บางรุ่นต้องเปิด “การเชื่อมต่อ OTG” ในตั้งค่าก่อน)

2. เลือกแบบติดตั้ง

ไม่ต้องเลือกรุ่นจอ: เกมตรวจจอ (ILI9341 / ST7789) แล้วตั้งสีให้เองตอนเปิดครั้งแรก

3. ติดตั้ง

กดปุ่มแล้วเลือกบอร์ด (ชื่อมักเป็น “USB Serial”, “CH340” หรือ COM) แล้วกดเชื่อมต่อ

ใช้เวลาประมาณ 1–3 นาที อย่าถอดสายหรือปิดจอมือถือระหว่างนี้ · ค้างที่ “กำลังเชื่อมต่อ” นาน: กดปุ่ม BOOT ที่บอร์ดค้างไว้แล้วลองใหม่
ตั้งค่าขั้นสูง / บันทึกการทำงาน

บอร์ดต้องมีเกม Pocket Fishing อยู่ (เวอร์ชัน 1.0.13 ขึ้นไป) · เกมจะเริ่มใหม่เองหนึ่งครั้ง

    
ไฟล์เซฟใช้ได้กับบอร์ดตัวเดิมเท่านั้น และแก้ไขไม่ได้ (ไฟล์ที่ถูกแก้ เกมจะไม่รับ) เก็บไฟล์ไว้ในคอมหรือมือถือให้ดี

    3. 
      
  3. อยากเริ่มใหม่: กระเป๋า (เมนู) › Settings › NEW GAME แตะ 2 ครั้ง (ไม่ต้องล้างเครื่อง) · เล่นครั้งแรกมีสอนทีละขั้น
