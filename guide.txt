Pocket Fishing  v1.0.7  -  คู่มือการเล่น
=========================================

เกมตกปลาสบายๆ บนจอ CYD (ESP32-2432S028R)
ตกปลา สะสมลงสมุด เลี้ยงปลาในตู้ อัปเบ็ด ต่อเรือ แล้วออกไปตกปลาถึงทะเลลึก


1. เปิดเครื่อง
--------------
- เปิดครั้งแรก: แตะเครื่องหมาย + ทั้ง 4 มุม เพื่อปรับจอสัมผัสให้ตรง (ทำครั้งเดียว)
- หน้าปก Pocket Fishing: แตะจอตรงไหนก็ได้เพื่อเริ่ม
  (ถ้าเคยเล่นแล้ว: หน้าปกขึ้น 3 วินาที แล้วไปที่ตู้ปลาของคุณเอง)
- เล่นครั้งแรก: เกมสอนทีละขั้น ตั้งแต่ตู้ปลาว่าง -> ไปตกปลาตัวแรก -> กลับมาดูมันในตู้


2. ตกปลา
--------
  1) แตะที่น้ำ = เหวี่ยงเบ็ด
  2) รอทุ่นกระตุก (มี "!") แล้ว "แตะให้ทัน"
  3) ดึงปลา: แถบด้านซ้ายมีปลาเด้งขึ้นลง
       กดจอค้าง = กล่องเขียวลอยขึ้น / ปล่อย = กล่องตกลง
       ให้ปลาอยู่ในกล่องเขียว แถบข้างๆ จะเต็ม = ได้ปลา
       ปลาหลุดกล่องนาน แถบหมด = ปลาหนี
  4) ได้ปลา: ขึ้นการ์ด ชื่อ ดาว น้ำหนัก ราคา (ขายเป็นเหรียญให้เอง)
     ปลาอยู่ในกล่องเกือบตลอด = PERFECT ได้เหรียญ 2 เท่า

- เงาปลาในน้ำบอกขนาด: เงาเล็ก = ปลาธรรมดา, เงาใหญ่ = ปลาดาวสูง
- ปลาบางชนิดออกเฉพาะกลางคืน หรือตอนฝนตก (สมุดปลาบอกไว้)
- ปุ่มเหยื่อมุมซ้ายล่าง: แตะเพื่อเปลี่ยนเหยื่อ
    Bread (ขนมปัง) ฟรีไม่จำกัด / Worm, Shrimp = ปลาดาวสูงมากินบ่อยขึ้น
    Gold Bait = ปลา 5 ดาวมากินบ่อยมาก
- บางครั้งตกได้ของแทนปลา: ไม้ เชือก เศษเหล็ก เปลือกหอย (ใช้ต่อเรือ อัปไซ)


3. ด่านและแผนที่
----------------
- แตะป้ายชื่อที่มุมขวาบน = ดูเควสของที่นี่ (ทุกที่เหมือนกัน)
    ตกครบ 6 ชนิด / ตกที่นี่ให้ครบ N ตัว / น้ำหนักปลารวมเกิน X kg
- ครบแล้วจะมี "เงายักษ์" โผล่ในน้ำ = บอสของที่นั้น ตกบอสได้ = ผ่านด่าน เปิดที่ใหม่
- MENU > MAP = เดินทางไปที่ที่เปิดแล้ว
- ทะเลต้องมีเรือ: ต่อที่ MENU > WORKSHOP > BOAT (ใช้ของที่ตกได้แถวชายฝั่ง)
- เบ็ดเก่งขึ้นเองเมื่อตกปลาไปเรื่อยๆ (แถบมุมซ้ายบน) เบ็ดดี = กล่องเขียวใหญ่ ดึงง่าย


4. ตู้ปลา
---------
- MENU > AQUARIUM หรือวางเครื่องไว้เฉยๆ 1 นาที ตู้ปลาจะขึ้นมาเอง
- ปลาทุกชนิดที่เคยตกได้ ลงตู้ได้ (ไม่ต้องเก็บตัวจริง) ใส่ได้ 12 ตัว
- เคาะจอ (แตะตรงไหนก็ได้):
    น้ำขุ่น = ทำความสะอาด / ปลาหิว = โรยอาหาร
    ดูแลดีๆ ปลาจะเชื่อง แล้วว่ายมาชนกระจกตรงที่แตะ
- ปัดซ้าย/ขวา = เปลี่ยนฉากตู้ (ซื้อฉากเพิ่มที่ SHOP > TANK)
- ปุ่มเฟืองซ้ายล่าง = เลือกปลาลงตู้ / แต่งตู้ (DECO)
- ปุ่มเบ็ดขวาล่าง = กลับไปตกปลา (มี "!" = ไซมีของ)
- ไม่แตะจอ 5 วินาที ปุ่มทั้งสองจะซ่อน แตะจอแล้วกลับมา
- ปุ่มฟันเฟือง: มีตู้จำลองย่อส่วน (ปลาว่ายจริง) กด < > ดูตู้ฉากอื่น
    FISH = แตะปลาเพื่อใส่/เอาออก (กรอบฟ้า = อยู่ในตู้)
    DECO = แตะของ แล้วแตะจุด 1-4 ในตู้จำลอง / ไม่ถือของแล้วแตะจุด = เอาออก


5. ไซดักปลา
-----------
- ทุกที่ที่เปิดแล้วมีไซในน้ำ ดักปลาเล็กและของเองตลอด
- มี "!" เหนือไซ = แตะเพื่อเก็บ (ดู "!" บนแผนที่ได้ว่าที่ไหนมีของ)
- อัปไซให้ใส่ได้มากและเร็วขึ้นที่ WORKSHOP > TRAP


6. ไอคอนในบ่อ และเมนู
---------------------
มุมขวาล่างของบ่อ:  ตู้ปลา = ไปที่ตู้ปลา   กระเป๋า = เปิดเมนู
เมนู (ไอคอนใหญ่ 6 อัน):
  Aquarium   ตู้ปลา
  Map        แผนที่ ("!" = ไซที่ไหนสักที่มีของ)
  Shop       ซื้อเหยื่อ ฉากตู้ปลา ผู้ช่วยดูแลตู้ ของแต่งตู้
  Workshop   เบ็ด เรือ ไซ แลกของ/ขายของ
  Fish Book  สมุดปลา: จำนวน ตัวใหญ่สุด ดาว
  Settings   ความสว่างจอ (- / +), NEW GAME, เลขเวอร์ชัน
NEW GAME = เริ่มเกมใหม่ทั้งหมด: แตะ 1 ครั้ง ปุ่มเปลี่ยนเป็น TAP AGAIN
           แตะซ้ำภายใน 3 วินาที = ลบเซฟ (ค่าจอสัมผัสกับความสว่างยังอยู่)


7. จอยบลูทูธ (ไม่ต้องมีก็เล่นได้)
---------------------------------
ใช้จอย ShanWan Q36 (GamepadSpace-Q36) หรือจอย BLE ที่คล้ายกัน
- เปิดจอย: กด L + X + Home ค้างพร้อมกันจนไฟกะพริบ บอร์ดจะต่อเอง ("Gamepad connected")
    ปุ่มลูกศร   เลื่อนลูกศรบนจอ
    A          แตะจอ (กดค้าง = นิ้วแตะค้าง ใช้ตอนดึงปลา)
    B          ย้อนกลับ
    +          เมนู            -   เปลี่ยนเหยื่อ
    X          เก็บของจากไซ    Y   สลับ บ่อตกปลา <-> ตู้ปลา
    L / R      เปลี่ยนฉากตู้     L2 / R2   จอมืดลง / สว่างขึ้น
